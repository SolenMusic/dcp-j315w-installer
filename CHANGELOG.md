# Changelog

## 0.1.0

- Combined graphical macOS installer with independently selectable Printing and
  Scanning components, using printing 0.1.1 and scanning 0.1.0.
- Native setup app for Bonjour discovery, IPv4 configuration and selective removal.
- Pinned SHA256-verified component releases; no driver source forks.
- Universal Intel/Apple Silicon builds and disposable-runner package tests.
